# 🚀 Sales Predictor App | Machine Learning + Streamlit

> 📊 Turn advertising budgets into smart sales predictions  
> Built using Machine Learning & deployed as a web app

---

## 🌟 Overview
This project is a **Machine Learning web application** that predicts product sales based on advertising spend.

💡 It answers a real business question:  
**“If I invest in advertising, how much sales can I expect?”**

---

## 🎯 Features
✔️ Predict sales using:
- 📺 TV advertising budget  
- 📻 Radio advertising budget  
- 📰 Newspaper advertising budget  

✔️ Instant prediction using trained ML model  
✔️ Simple and interactive web interface  
✔️ Real-world dataset  

---

## 🧠 Model Used
- 📌 Linear Regression  
- Learns relationship between advertising spend and sales  
- Fast, simple, and effective for prediction  

---

## 🛠️ Tech Stack
- 🐍 Python  
- 🤖 Scikit-learn  
- 📊 Pandas & NumPy  
- 🌐 Streamlit  

---

## ▶️ Run Locally

```bash
pip install -r requirements.txt
